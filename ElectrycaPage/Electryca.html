Electryca - Breaking Fear

About

Context

This is my first game and an entry project from my first semester.

Task

We had 2 weeks to make a playable prototype, starting from the general game idea, to the first blockout, all the way to the finished prototype.

Gameplay

It´s a first person horror game, set in an old and seemingly abandoned factory.
The player has to solve interconnected riddles to uncover the truth about the factory, all while avoiding a rogue construction robot.
